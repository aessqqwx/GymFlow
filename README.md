# GymFlow 1.5

**Тренировки, питание, прогресс и локальная музыка в одном Android-приложении.**

Kotlin · Jetpack Compose · Material 3 · Media3 · Android 8.0+

## Возможности

| Раздел | Возможности |
| --- | --- |
| Тренировки | Зал и дом, программа по расписанию, выбор упражнений, подходы, отдых и пауза |
| История | Повтор тренировки, шаблоны, заметки, оценка самочувствия |
| Прогресс | Замеры, цели, рекорды, серии, XP, достижения и отчёт за месяц |
| Питание | Калории, белок, вода и дневные цели |
| Музыка | Импорт локальных файлов, очередь, плейлисты, фоновое воспроизведение |
| Настройки | RU/EN, темы, палитры, размер текста, напоминания, JSON-резервные копии |

## Сборка и загрузка

В Actions запустите **Build GymFlow APK**. После успешного завершения скачайте артефакт **GymGlow_v1.5**. Он содержит APK и SHA-256.

```sh
bash gradlew :logic-tests:run :app:assembleDebug :app:lintDebug --no-daemon
sh tools/final-checks/run.sh
```

CI также запускает APK на Android 15 и сохраняет скриншот, UI-дерево и crash log. Эти проверки не заменяют ручную проверку всех экранов, уведомлений и аудио на устройстве.

## Публикация

Исходники находятся в публичном `aessqqwx/GymGlow-Test`. После успешных тестов, lint и проверки запуска CI публикует тестовый APK 1.5 в Releases этого репозитория.

APK устанавливается отдельным приложением **GymGlow Test** (`com.aess.gymflow.test`), рядом с прежним GymFlow. Данные прежней установки остаются в ней. Тестовая сборка использует стандартную debug-подпись CI; прежний ключ подписи не публикуется в этом репозитории.
