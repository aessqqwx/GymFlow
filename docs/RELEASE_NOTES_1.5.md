# GymFlow 1.5

Обновлены анимации и жесты, отображение версии в настройках и сброс перемотки при смене трека. Устанавливается отдельно как GymFlow (`com.aess.gymflow.test`), не заменяя прежний GymFlow. Прежние данные остаются в старой установке; при необходимости их можно перенести JSON-экспортом и импортом. Используется стандартная debug-подпись CI.

APK: GymGlow_v1.5.apk. Это тестовая debug-сборка. Перед публикацией нужно дождаться успешного завершения обеих задач workflow android-build.yml.
